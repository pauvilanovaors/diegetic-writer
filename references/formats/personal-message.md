# Personal Message Format

Prioritize immediacy, relationship, and a clear practical or emotional purpose.

## Components

1. Optional address or greeting.
2. Context in one compact unit.
3. Request, update, invitation, or reaction.
4. Necessary detail such as time, place, or response.
5. Optional familiar closing.

For a WhatsApp-style message, keep it short and conversational without requiring modern platform names at Levels 3–4. For a conversation, use speaker turns with meaningful responses, not alternating monologues. For a social media post, use a public-facing hook, concise substance, and only platform conventions plausible in the selected world. Do not add hashtags by default.

Immersion comes from what the speaker notices, withholds, and assumes—not from making every line slang or ritual. Preserve brevity unless the user requests a longer exchange.
